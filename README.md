# 🏮 いずれてっぺん超えれる？ — 動作する試作版 v0.1

## 起動方法
Node.js 20以上をインストールし、このフォルダで以下を実行します。

```bash
npm install
npm start
```

ブラウザで http://localhost:3000 を開きます。同じ部屋番号・招待URLで複数端末から入れます。外部公開する場合は Node.js / WebSocket 対応ホスティングに配置し、**HTTPS** を使ってください。Androidのマイク利用にはHTTPSが原則必要です。

## この試作版でできること
- 6桁の部屋番号で作成・参加、招待リンク、観戦者とプレーヤーの区別
- 主催者が最大10人のプレーヤーを選択、マイクテスト、準備OK
- 難易度（初級・中級・上級）、問題数、時間制限あり・なし
- 5秒カウントダウン、ブラウザによる英語読み上げ
- 各プレーヤーの音声を3回まで聞き、15秒録音・録り直し・確認送信
- WebSocket経由の音声伝言、観戦者向け音声、答え合わせと原文・訳文
- 主催者による一時停止と休憩メッセージ、再開予定表示
- OpenAI APIキーを設定すると音声の英語文字起こし（Whisper）

## 文字起こし（任意）
環境変数 `OPENAI_API_KEY` をサーバーに設定して起動します。設定がなければ録音再生は動きますが、文字起こしは「API未設定」と表示されます。キーをHTMLやブラウザ側には絶対に書かないでください。API利用料金が別途かかります。

### 注意点
- サーバー再起動時に部屋と録音は消えます。音声はメモリ内で扱います。
- ブラウザの読み上げ音声・声質は端末によって異なります。
- HTTPSなしの別端末アクセスではマイクが使えない場合があります。
- 試作版の通信やルーム保護は本番品質ではありません。個人情報や非公開音声の本番運用はしないでください。
- 音声データが大きいとWebSocketのサイズ制限に当たる可能性があります。
